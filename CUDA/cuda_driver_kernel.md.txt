#include <cuda.h>: Includes the core CUDA headers needed for GPU-specific data types and hardware interaction.
extern "C": Tells the compiler to use standard C-style linking. This is often necessary if you plan to call this CUDA code from another language (like Python, Java, or C#) or use the low-level Driver API to load the compiled .ptx file. (C++ Name Mangling)
__global__: This is a CUDA keyword. It marks the function as a kernel, meaning it is launched from the CPU (Host) but executes on the GPU (Device). (Function Execution Space Specifiers)
void addKernel(int *data, int N): Kernels must return void. They operate by modifying the data directly at the memory address (*data) provided.
int idx = threadIdx.x + blockIdx.x * blockDim.x;: This is the "ID calculation." Because the GPU runs this function thousands of times simultaneously, each "worker" (thread) uses its unique coordinates (threadIdx, blockIdx) to calculate which specific index in the array it should handle. Thread Hierarchy
if (idx < N): This is a safety check (a "guard"). It ensures that if you have more threads than data points, the extra threads don't try to access memory outside the array's bounds.
data[idx] += 5;: The actual work. Each thread adds 5 to its assigned integer in the array.
